### ChatGPT Images Prompt — Configuration A: "Momentum Flow"

```
Create a mobile game UI mockup screenshot for a word puzzle game called "WordRun" in portrait orientation (390x844 pixels, iPhone aspect ratio).

OVERALL MOOD: High-energy arcade rhythm, flow state, speed-focused. Clean and focused with minimal distractions.

LAYOUT (top to bottom):
1. TOP HEADER BAR (60px height, semi-transparent):
   - Small settings gear icon (left, 60% opacity, muted)
   - Small coin balance display (right, 60% opacity, muted)

2. COMBO BANNER (prominent, persistent, top-center overlay):
   - Large teal ribbon with "COMBO x4" text
   - Text uses orange-to-yellow gradient, 140% larger than typical
   - Subtle glow effect pulsing around the banner
   - Positioned to overlap header slightly

3. WORD GRID (center-upper, 40% of screen):
   - 3x4 crossword-style grid with rounded square tiles
   - Completed tiles: bright green with white letters, slight 3D bevel
   - Empty tiles: dark grey outlines

4. WORD-IN-PROGRESS DISPLAY (150% enlarged, center):
   - Large glossy blue pill shape directly above wheel

   - Letters are 10% larger than typical, high readability

   - Small hint button (right of wheel, lightbulb icon)

8. CHARACTER MASCOT (small, corner):
```

### E.3 Decision Leverage Points

These are the UI choices that have the highest impact on player experience and differentiate configurations most significantly. Prioritize these decisions.

#### Critical Leverage Point 1: Combo Banner Persistence vs. Transience

| Decision | Config A | Config B | Config C |
|----------|----------|----------|----------|
| Visibility | Persistent (always visible during combo) | Transient (appears, celebrates, exits) | Hidden (or text-only, minimal) |
| Size | 140% baseline | 160% baseline | 0% or small text |
| Animation | Subtle glow pulse | Elaborate 1300ms entrance | None or fade |

**Impact:** Determines whether game feels like "arcade rhythm" (A), "party celebration" (B), or "quiet puzzle" (C). This single component drives 30% of emotional perception.

**Recommendation:** Test all three approaches with user surveys asking "How energizing/calming did this session feel?" (1-5 scale)

---

#### Critical Leverage Point 2: Particle System Intensity

| Decision | Config A | Config B | Config C |
|----------|----------|----------|----------|
| Per-word particles | 15-20 | 30 per tile | 0-3 |
| Milestone particles | 40-60 | 200-350 | 0-12 |
| Chain completion | Standard burst | 500+ multi-stage cascade | Gentle 12-particle drift |
| Variety | Sparkles only | Confetti, hearts, stars, sparkles | Soft sparkles only |

**Impact:** Directly affects perceived "reward magnitude." More particles = more dopamine. Fewer particles = more calm. This is the primary visual difference players will notice.

**Recommendation:** Create particle intensity slider for user testing: "How rewarding did word completion feel?" correlated with particle count.

---

#### Critical Leverage Point 3: Character Mascot Reactivity

| Decision | Config A | Config B | Config C |
|----------|----------|----------|----------|
| Size | 80% baseline | 130% baseline | 60% baseline |
| Reacts to | Milestones only (x3, x5, x10) | Every single word | Nothing (minimal breathing) |
| Celebration intensity | Quick fist-pump (500ms) | Full dance (2000ms) | Subtle nod (600ms) |
| Error response | None | Encouraging recovery | None |

**Impact:** Character creates parasocial relationship. More reactivity = more emotional connection but also more distraction. Less reactivity = more focus but less companionship.

**Recommendation:** Include qualitative question: "Did Ruut (the character) enhance or distract from your experience?"

---

#### Critical Leverage Point 4: Animation Timing Philosophy

| Decision | Config A | Config B | Config C |
|----------|----------|----------|----------|
| Tile animation | 300ms (fast) | 1500ms (elaborate) | 800ms (slow, gentle) |
| Core cycle | Normalized 300ms rhythm | Variable (600-3000ms) | Normalized 800ms rhythm |
| Easing | ease-out-back (springy) | spring, bounce (playful) | ease-in-out-sine (gentle) |

**Impact:** Animation timing directly affects perceived game speed. Config A feels "fast." Config B feels "rewarding but slow." Config C feels "meditative."

**Recommendation:** Measure words_per_minute across configurations. Hypothesis: Config A highest, Config C lowest, Config B in middle (slowed by celebrations).

---

#### Critical Leverage Point 5: Background Complexity

| Decision | Config A | Config B | Config C |
|----------|----------|----------|----------|
| Style | Simplified gradient | Dynamic thematic (candy land) | Minimal (solid or 95% blur) |
| Animation | None | Responds to combo level | None |
| Visual noise | Low | High | Very low |

**Impact:** Background affects cognitive load. Busy backgrounds compete for attention. Simple backgrounds keep focus on gameplay but may feel "cheap."

**Recommendation:** Eye-tracking study (or heuristic): Where do players look during gameplay? Background should not draw attention away from grid and wheel.

---

#### Critical Leverage Point 6: Audio/Haptic Default State

| Decision | Config A | Config B | Config C |
|----------|----------|----------|----------|
| Haptic default | On (medium) | On (heavy) | Off (opt-in) |
| Audio complexity | Rising chimes, quick | Musical phrases, rich | Single notes, minimal |
| Error feedback | Soft womp | Encouraging bloop | Silence |

**Impact:** Audio/haptic are 50% of "juice." Config B relies heavily on audio to create party atmosphere. Config C's silence is intentional for calm.

**Recommendation:** Test audio-off versions of all three configs. Does Config B still feel celebratory without sound? Does Config A maintain rhythm without haptic ticks?

### E.4 Configuration Selection Matrix

For production, consider offering users the choice or using player behavior to auto-assign:

| Player Behavior Signal | Recommended Config | Rationale |
|------------------------|-------------------|-----------|
| High WPM (>40), long sessions | **A: Momentum Flow** | Speed-focused players want rhythm |
| Social sharing, achievement-focused | **B: Celebration Cascade** | Reward-motivated players want dopamine |
| Short sessions, late-night play | **C: Zen Focus** | Relaxation-seeking players want calm |
| New user (unknown) | **A: Momentum Flow** | Middle-ground, most game-like |
| Accessibility settings enabled | **C: Zen Focus** | Reduced motion, sensory sensitivity |
| Previously disabled audio/haptics | **C: Zen Focus** | Indicates preference for quiet |
| Previously purchased cosmetics | **B: Celebration Cascade** | Values visual expression |

### E.5 Risk Mitigation Notes

1. **Config B Performance Risk:** 500+ particles on older devices may cause frame drops. Implement particle count scaling based on device capability.

2. **Config C "Empty" Perception Risk:** Some players may perceive minimal design as "unfinished" or "cheap." Counter with high-quality typography and subtle polish details.

3. **Config A "Pressure" Risk:** Persistent combo banner may create anxiety for casual players. Monitor for elevated churn in first 5 levels.

4. **Cross-Config Consistency:** Players who see multiple configs (e.g., through reinstall or A/B reassignment) may be confused. Ensure core gameplay mechanics are identical; only presentation differs.

5. **Character Attachment Risk (Config C):** Minimizing Ruut may reduce long-term emotional attachment. Monitor D30 retention for Config C specifically.
